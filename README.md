## What is REasy?

**REasy** is a toolkit and editor for working with RE Engine game data.

It brings together a growing set of tools for browsing game archives, opening and editing supported file formats, building mod projects and exporting finished mods.

REasy can be used for tasks such as:

- Browsing and extracting files directly from RE Engine PAK archives
- Creating and managing mod projects
- Viewing and editing supported RSZ files
- Working with scenes, GameObjects, prefabs and resources
- Viewing supported meshes and textures
- Converting and replacing textures
- Previewing and replacing supported audio
- Generating and improving `.list` files
- Searching game files and paths
- Exporting projects for Fluffy Mod Manager
- Creating PAK-based mods
- Comparing RSZ files and researching game data

REasy is actively developed, so supported formats and tools continue to expand.

For the application itself, visit the main:

- [REasy Repository](https://github.com/seifhassine/REasy)
